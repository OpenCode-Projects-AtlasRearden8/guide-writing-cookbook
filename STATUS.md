# STATUS.md — Guide-Writing Cookbook

**Project:** The Guide-Writing Cookbook — plain-friendly manuals, the Asdale way.
**Owner:** Asdale Dynamics, LLC (Dylan Asdale). MIT licensed, local-first.

## What was built

A complete, tested guide for writing beginner manuals, in Markdown, with a
build script that turns it into a static site and a print-ready single page.

- **docs/** — the book:
  - `00-introduction.md` — who it's for, the Asdale way in one paragraph, how
    it complements open-book-starter-template (and deliberately doesn't
    repeat it).
  - `01-pick-a-bleeding-topic.md` — finding pains (time/confusion/money/
    dignity tax), scoring candidates, the one-sentence pain test.
  - `02-scope-first-edition.md` — the five-point finishability test, the
    one-project rule, the chapter diet, scoping worksheet.
  - `03-plain-english-rules.md` — 15 drafting rules, banned grading words,
    the step template, before/after example.
  - `04-lesson-rhythms.md` — the anchor/setup/steps/check/breathe/next beat,
    beat-length rules, lesson genres table, rhythm test.
  - `05-edit-for-dignity.md` — the dignity principle, three condescension
    patterns, where warmth actually comes from, word swaps, revision pass.
  - `06-printables-and-tools.md` — the artifact ladder (facts page, checklist,
    cheat sheet, session card, template, tool), printable fitness test,
    tool-hunting questions, worked example.
  - `07-verify-every-claim.md` — claim taxonomy, the verification loop,
    cross-checking, harmlessness guardrails, fragile-claim ledger.
  - `08-ship-docs-site-pdf.md` — the docs → site → PDF loop, build hygiene,
    test contract, release checklist, "editions finish; projects continue."
  - `checklist-tone.md` — the one-page tone checklist (respect/clarity/
    rhythm/honesty/warmth/ship).
  - `glossary.md` — 27 plain-English definitions, alphabetized (tests enforce
    alphabetical order).
  - `cards/` — 9 one-page chapter-recipe cards, one per chapter/intro.
- **build.py** — stdlib + `markdown` (already present); generates 11 chapter/
  special pages, 9 card pages, `cards.html`, `index.html`, and `print.html`
  (all chapters + checklist + glossary + cards, print CSS, page breaks between
  chapters). No network, no analytics, system fonts only.
- **site/** — generated output (rebuilt by `python3 build.py`).
- **tests/test.py** — 24-test verification suite (see below).
- **README.md** — overview, run/test/print instructions, credit to
  Asdale Dynamics, LLC.
- **LICENSE** — MIT, exact line `Copyright (c) 2026 Asdale Dynamics, LLC`.

## How to run it

    python3 build.py        # rebuild site/ from docs/
    python3 tests/test.py   # run the verification suite
    # open site/index.html in a browser
    # PDF: open site/print.html -> File -> Print -> Save as PDF

## Known gaps / future work

- **No automated visual testing.** The print CSS (page breaks, black-and-white
  rendering) is verified by code inspection and by the browser print preview
  step in the release checklist, not by pixel-diff testing.
- **PDF is browser-generated by design** (local-first): opening
  `site/print.html` → Print → Save as PDF. No CI PDF renderer (weasyprint/pandoc)
  is wired in; `build.py` deliberately ships with zero extra dependencies.
- **Edition-two scent trail, not edition two:** chapter 2's "parking lot"
  workflow (`ideas.md`) is described but the repo doesn't pre-create that file
  for writers.
- Syntax highlighting and full-width tables in very narrow cards are untested;
  current content uses inline code only, where rendering is verified.
- Reading-progress or search features intentionally omitted (local-first,
  static-only ethos).
