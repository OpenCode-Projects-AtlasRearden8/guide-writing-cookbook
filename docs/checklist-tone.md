# The Tone Checklist

Keep this beside your keyboard. Run it on any page before you call it done.
Each line is a yes/no question; anything not yes is a rewrite job.

## Respect

- [ ] No sentence grades the reader's ability (*just*, *simply*, *easy*, *obvious*, *basic*).
- [ ] No commands over feelings ("don't panic", "relax"). Instead: state what's reversible or what's true.
- [ ] Confusion is treated as situational, never personal.
- [ ] Praising anything? It names the difficulty, and the difficulty was real.
- [ ] No jokes at the reader's expense (situational or self-directed only).

## Clarity

- [ ] Second person, present tense throughout.
- [ ] One instruction per sentence; sentences default under 25 words.
- [ ] Every screen name quoted or in code style, matching the screen exactly.
- [ ] Every expectation stated after the action ("a panel opens on the right").
- [ ] Jargon defined in the sentence it first appears, or removed.
- [ ] A check for the reader at least every five steps.
- [ ] Warnings come *before* the risky step, not after.

## Rhythm

- [ ] Lesson starts by anchoring the reader: where they are, what they'll have.
- [ ] Setup steps are five or fewer; step groups are five or fewer.
- [ ] A natural stopping point lands within the last third, and says so.
- [ ] Recovery for the most likely failure is within one paragraph.

## Honesty

- [ ] Every volatile claim carries a date (or lives in `claims.md` with one).
- [ ] Procedures verified fresh end-to-end, on a clean state, by me.
- [ ] Nothing here reads like medical, legal, or financial advice — and says so if the topic brushes it.
- [ ] Numbers over adjectives: "about 40 seconds," not "quickly."

## Warmth

- [ ] At least one place the reader is told it's okay to stop.
- [ ] At least one honest admission (something I found annoying, how long my first attempt took).
- [ ] Contractions welcome; the page sounds like a person, spoken aloud once.
- [ ] The reader's time: every sentence here earns its space.

## Ship

- [ ] Read every paragraph out loud once, and heard a calm friend, not a presenter.
- [ ] Placeholder text gone.
- [ ] Chapter joins the build and the test suite passes.
