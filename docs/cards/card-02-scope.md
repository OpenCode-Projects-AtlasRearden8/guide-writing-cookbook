# Recipe Card 2: Scope a First Edition You Can Finish

**Use when:** your outline is growing faster than your week.

## The five-point test

- [ ] Draft fits my real available hours this week (count them).
- [ ] Every page is load-bearing — the reader could finish without it, it's out.
- [ ] I can verify every page myself, today.
- [ ] It stands alone — no "see the future chapter 12."
- [ ] "Done" is a concrete list: N chapters, M pages, Q printables, one passing build.

## The one-project rule

- [ ] One project, taught to done. Not one *area*.
- [ ] One alternative mentioned in one paragraph, max.
- [ ] Chapter diet: intro + setup + 2–4 spine chapters + one recovery page.

## Fill the scoping worksheet (10 minutes)

- [ ] Project sentence: reader does X, gets Y.
- [ ] Done looks like: ___ chapters, ___ pages, ___ printables.
- [ ] Hours I have this week: ___
- [ ] Setup chapter's first sentence: "By page 4 you will have ___ running."
- [ ] Recovery page lists my 3 most likely failure modes.
- [ ] Edition-two wishes parked in `ideas.md` — officially deferred, zero guilt.

## The honest signal

Feeling slightly disappointed with the size? Good. That's the scope that finishes.
