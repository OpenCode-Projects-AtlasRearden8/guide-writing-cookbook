# Recipe Card 3: Plain-English Drafting Rules

**Use when:** writing any draft, or stuck on a paragraph that "reads wrong."

## Draft rules (keep at hand)

- [ ] "You" + present tense. "Open the menu," not "the user opens the menu."
- [ ] One instruction per sentence.
- [ ] Sentences default under 25 words.
- [ ] Vocabulary a tired 12-year-old knows — because every adult shares it.
- [ ] Define jargon in the sentence where it first appears.
- [ ] Active voice. Numbers over adjectives ("about 40 seconds").
- [ ] Screen text exactly as shown: `Settings`, "Export as PDF".
- [ ] Explain what happens after the action: "the button grays for a second."
- [ ] Warnings *before* risky steps.
- [ ] Contractions welcome. Read it aloud once before moving on.

## Cut on sight

`simply` · `just` · `easy` · `obviously` · `basically` · `merely` · `actually`

They grade the reader. Delete the word, keep the sentence.

## Step shape

1. **Action:** "Click the Settings gear."
2. **Expectation:** "A panel opens on the right."
3. **Why** (when useful): "Export options live here."
4. **Check:** "You should see the version number at the bottom."

Every confusing place needs the expectation at minimum.
