# Recipe Card 0: Introduction — How to Read This Cookbook

**Use when:** starting a manual project, or handing this whole cookbook to someone else.

## First pass (one evening)

1. [ ] Read straight through, chapters 1–8, once. Don't take notes yet.
2. [ ] Pick a tiny practice project: one 5-page manual, one printable, done this week.
3. [ ] Fill in the one-sentence pain test (Chapter 1) for your real project topic.

## Ongoing use

- [ ] Keep the **tone checklist** open while editing, not while drafting.
- [ ] Grab the matching **recipe card** when starting each phase.
- [ ] Re-read a chapter only when it fails in practice — then fix your habit, not your copy.

## The three rules to tape somewhere visible

1. Respect the reader's tiredness.
2. A claim you haven't verified is a guess in a lab coat.
3. Ship one small true thing instead of half a big vague one.
